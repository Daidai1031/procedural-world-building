Every study so far answered a different question by choosing what to read: a fixed colour, this vertex's own position, which way it faces, distance to a point, the camera's own angle, a photograph, precomputed water depth, or time. None of them is "the correct shader" — each is a tool built for one question, and most say nothing useful about the others.

Reach for **Height + slope** when the question is "what should this ground look like," since it only needs the mesh itself. Reach for **Water diagnostic** when the question needs real state from somewhere else — a simulation, a save file, anything the mesh alone cannot answer. Reach for **MatCap** or **Fresnel** for a convincing look without computing real light. Keep **Vertex displacement** to a cosmetic flourish, never something a digging tool or a save file needs to be true.

Switch **Shader strategy** through every option here on the same terrain — the geometry never changes, only which question is being asked of it.
