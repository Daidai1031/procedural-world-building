Imagine pouring rain evenly over the whole map and watching where it settles: water can only pool as high as the lowest rim it would have to spill over to reach the edge. That is computed once here, from the exact height formula that builds the Ground shape — so puddles sit in real dips of this terrain, not wherever looks convincing.

That computation runs on the CPU as one flat grid of numbers. Turning it into something the GPU can read uses the same trick Step 06 used for a photo: take a world position, scale and shift it into a 0-to-1 lookup — except this picture is data, not a photograph.

Drag **Puddle threshold** to hide shallow dips and keep only the deepest ones full, the same soft threshold Steps 03 and 04 used for snow and rock.

Switch **Density shape**: Caves and Floating islands still show this same puddle pattern, because it only ever reads Ground's height formula — a mismatch worth noticing, not a bug.
