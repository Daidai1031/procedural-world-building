A house blueprint says "the door sits 2 metres from the left wall" — measured from that house's own corner. Move the house anywhere in the city and the blueprint still reads 2 metres: that is **local position**. Now say where that same door sits on a city map instead — move the house, and that number changes. That is **world position**.

The dark dots floating above each chunk mark its own local "zero". The pink dot marks the one shared world "zero", sitting right where the chunks meet. Toggle **Local position** and **World position** below: same stripe rule both times, only which dot it counts from changes. Local space restarts at each chunk's own dot, so the seam breaks. World space counts from the shared dot, so it does not.

A value can also come from a vertex's own data (an **attribute**), stay fixed for the whole chunk (a **uniform**), or blend smoothly between vertices the way this stripe colour does (a **varying**). A third space, **view space**, moves with the camera instead of any object — useful later for a camera-facing effect.
