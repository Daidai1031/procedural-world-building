A line can fit through a gap that is too narrow for a resident. Check the body's width along the whole route.

Increase **Body radius**, then press **Play**. The blocked section has red crosses; the resident stops before it.

Now try **Block passage** or **Open passage**. Recheck the same route after each edit. A wider passage may allow travel, but it does not prove that the destination is a suitable home.

Under **Inspect**, enable **Show terrain experiment**. Compare Before / After and change Corridor width to see the path reshape a copy of the ground.
