When a robot digs, dust rises. You cannot follow every speck by eye, but a computer can, if each speck gets its own small **notebook page**.

That page is the **particle**. It records where the speck is, which way it is moving, how old it is, and how long it will last. Nothing on the page says what the speck looks like.

Looks are a separate choice. The same page can be drawn as a hard dot, a soft puff, or a streak. Changing the drawing is like changing a costume: the person underneath does not change.

Click any speck to open its page, or use the arrows. Then switch **Look** between Dot and Puff. The speck changes shape, but every number on its page stays exactly the same.

This split is useful later. You can redesign how the dust looks without touching how it moves.
