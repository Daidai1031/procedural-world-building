Typing every instruction by hand does not scale. A better trick is to write one starting symbol and one rewriting rule, then let the computer apply the rule again and again.

The starting symbol is called the **axiom**. Ours is `F`. The rule is `F → F + F`: every `F` is swapped for `F + F`. Symbols with no rule, like `+`, stay as they are.

| Generation | Instructions | F count |
| --- | --- | --- |
| 0 | `F` | 1 |
| 1 | `F + F` | 2 |
| 2 | `F + F + F + F` | 4 |

One full round of swapping is one **generation**. Each round reads only the old string, so new symbols wait for the next round. A system like this is called an **L-system**.

Press **Next Generation**. The bottom row of the panel shows what every old symbol became. Before you press again, predict how many `F` generation 3 will have. Lines can overlap, so count instructions, not strokes.
