A tree has thousands of branches. Drawing each one by hand would take forever, so this lesson gives the computer a few simple rules and lets it grow the rest. We start with the smallest piece: telling a pen how to draw.

Picture a pen that knows where it stands and which way it faces. It understands three instructions.

| Symbol | The pen does this |
| --- | --- |
| `F` | Move forward and draw a line |
| `+` | Turn left, draw nothing |
| `-` | Turn right, draw nothing |

So `F + F - F` means: draw, turn left, draw, turn right, draw. The spaces are only for reading.

Press **Next Instruction** and follow the highlighted symbol. Then change the angle to 90° and play it again. The same three instructions now draw a different shape.

Before you move on, ask yourself: did a `+` ever add a line?
