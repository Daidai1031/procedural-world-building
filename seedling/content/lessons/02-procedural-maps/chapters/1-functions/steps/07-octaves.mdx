One noise layer gives the landscape a single main feature scale. A noise stack samples several layers and combines their values. Each layer is called an octave. Here, each new octave doubles the frequency, adding smaller features to the larger forms.

Set Octaves to one, then increase it gradually. Look for new detail inside shapes you already recognize. The loop below repeats the sampling process, accumulating a weighted total. Its final division keeps the combined result on a comparable scale instead of making the terrain taller simply because more layers were added.
