Choose Terracing in Shaping. A continuous range of values is rounded into a small number of levels. Many neighboring samples now share the same height, creating shelves separated by sharper rises. This is quantization: replacing many possible answers with a smaller set.

Switch to Power curve. Heights still vary continuously, but values between zero and one become smaller when raised to this power. Lower ground becomes more prominent. Terracing changes the available levels; a power curve changes how values occupy the range. Return to Normal to compare both with the original field.
