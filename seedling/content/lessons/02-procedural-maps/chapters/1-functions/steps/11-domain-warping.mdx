Choose Domain warping in Shaping, then increase Warp strength from zero. Features bend and stretch because the function is sampled at displaced positions. Imagine pulling a printed map sideways before reading its heights.

The code creates two smooth offset fields, one for each ground coordinate. Warp strength scales those offsets before they are added to the original position. Unlike a terrace or power curve, the change happens before the final noise value is sampled. At zero strength, the offsets vanish and you read the original, unwarped field again.
