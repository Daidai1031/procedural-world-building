02 · The field crew

Four robots. Four ways to change a world.

Set a work area and let each specialist read the terrain, choose a task and leave a different mark behind.

  1. M
    01 · Extract

    Miner

    Scans for minerals, drills a radial tunnel and carries each find back into storage.

    scan → tunnel → collect
  2. G
    02 · Cultivate

    Gardener

    Surveys flatter ground and grows vegetation where the surface can support it.

    survey → plant → spread
  3. R
    03 · Connect

    Rigger

    Searches the high ground and raises antennas that extend the system’s reach.

    survey → raise → signal
  4. B
    04 · Shape

    Builder

    Cuts obstructions and fills damaged ground with soil recovered by the crew.

    cut → fill → level

    05 · How it is made

    From class notes to a lesson.

    Every lesson follows the same loop. Hover a step for detail.

    1. 01

      Class notes

      Start from the lecture notes and slides.

    2. 02

      Clarify in chat

      Talk through anything unclear with an LLM in one chat session.

    3. 03

      Exercise document

      The LLM drafts the write-up from the assignment, keeping plans apart from observed results.

    4. 04

      ~10-step plan

      Each step states one conclusion.

    5. 05

      One step at a time

      Build and check each step before starting the next.

    6. 06

      One parameter per visual

      The canvas shows a single parameter at a time, not a lab with every control.

    7. 07

      Read the code

      Source is explained to be understood, not written from scratch.

    8. 08

      Practice

      A short same-idea, new-case question closes the step.
