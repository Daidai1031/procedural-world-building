HOW IT IS MADE

From class notes to a lesson

Every lesson follows the same loop,
from class to review.

  1. 01

    Class notes

    Start from the lecture notes and slides.

  2. 02

    Clarify in chat

    Talk through anything unclear with an LLM in one chat session.

  3. 03

    Exercise document

    The LLM drafts the write-up from the assignment, keeping plans apart from observed results.

  4. 04

    A plan of ~10 steps

    Each step states one conclusion.

  5. 05

    Build one step at a time

    Build and check each step before starting the next.

  6. 06

    One parameter per visual

    The canvas on the right shows a single parameter at a time, not a lab with every control.

  7. 07

    Read the code

    Source is explained to be understood, not to be written from scratch.

  8. 08

    Practice question

    A short same-idea, new-case question closes the step for review.
